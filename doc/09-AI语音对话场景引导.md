# 📄 PRD：儿童AI英语语音对话（场景引导式）

---

# 一、产品概述

## 1.1 产品名称

儿童AI英语 - 场景语音对话模块

---

## 1.2 产品目标

为儿童提供一个**低压力、可引导的英语口语练习环境**，通过模拟真实场景对话，让孩子：

* 敢开口说英语
* 学会基础表达
* 在对话中自然习得句型

---

## 1.3 产品定位

👉 **引导式英语对话（Guided Conversation）**

区别于：

* ❌ 自由聊天（不可控）
* ❌ 语音评测（高压力）

---

# 二、核心设计原则

---

## 2.1 流程控制原则

```text
是否进入下一Step → 规则控制（确定性）
语言表达生成 → LLM生成（自然性）
```

---

## 2.2 儿童体验原则

* 不强调错误（No “Wrong”）
* 鼓励优先（Encouragement First）
* 不阻塞流程（No Dead End）
* 教学优先（Teach > Test）

---

## 2.3 系统架构原则

```text
ASR（语音识别） → 规则判断 → LLM生成 → TTS（语音合成）
```

---

# 三、功能范围

---

## 3.1 场景数量

初期设计 3 个场景：

1. Greeting（打招呼）
2. Self Introduction（自我介绍）
3. Ordering Food（点餐）

---

## 3.2 每个场景结构（每个场景对话脚本设计）

👉 每个场景由多个 Step 构成：

```text
Scene → Step1 → Step2 → Step3 → ...
```

---

## 3.3 Step 定义

每个 Step 包含：

```json
{
  "id": 1,
  "question": "What do you say in the morning?",
  "expected": ["good morning"],
  "hints": ["Good morning"],
  "teach": "In the morning, we say Good morning!"
}
```

---

字段说明：

| 字段       | 说明     |
| -------- | ------ |
| question | AI提问   |
| expected | 关键词匹配  |
| hints    | 前端提示按钮 |
| teach    | 教学提示   |

---

# 四、用户流程

---

## 4.1 完整流程

```text
进入场景
↓
AI播报问题（TTS）
↓
孩子语音输入
↓
ASR识别文本
↓
规则判断
↓
LLM生成回复
↓
TTS播放
↓
进入下一Step
```

---

## 4.2 流程图（核心逻辑）

```text
         +------------------+
         |   用户语音输入   |
         +--------+---------+
                  ↓
               ASR识别
                  ↓
         +--------+---------+
         | 规则匹配 expected |
         +----+--------+----+
              |        |
           命中     未命中
              |        |
              ↓        ↓
         直接通过   LLM语义判断
              |        |
              +----+---+
                   ↓
             LLM生成回复
                   ↓
                 TTS
                   ↓
               下一Step
```

# 五、核心逻辑设计

---

## 5.1 规则判断（主逻辑）

---

### 5.1.1 判断方法（MVP）

```go
func match(userText string, expected []string) bool {
    userText = strings.ToLower(userText)
    for _, e := range expected {
        if strings.Contains(userText, e) {
            return true
        }
    }
    return false
}
```

---

## 5.2 LLM辅助判断（仅在规则未命中时）

---

### 输入：

```json
{
  "user_input": "good morning teacher",
  "expected": ["good morning"]
}
```

---

### 输出：

```json
{
  "semantic_match": true
}
```

---

👉 注意：

* LLM **不能直接控制流程**
* 仅作为“兜底判断”

---

# 六、LLM生成模块

---

## 6.1 职责

LLM仅负责：

* 生成自然语言回复
* 表扬 / 鼓励
* 教学提示
* 简单拓展

---

## 6.2 输出格式（强制结构化）

```json
{
  "status": "pass" | "fail",
  "reply": "对孩子说的话",
  "hint": "提示（可选）",
  "expand": "拓展（可选）"
}
```

---

## 6.3 示例

---

### ✅ 正确回答

```json
{
  "status": "pass",
  "reply": "Great job! Good morning! What do you say in the evening?",
  "expand": "We also say good afternoon in the afternoon."
}
```

---

### ❌ 错误回答

```json
{
  "status": "fail",
  "reply": "It's okay! Let's try this: Good morning!",
  "hint": "Say: Good morning"
}
```

# 十一、非功能要求

---

## 11.1 性能

* 单轮响应 < 2s（理想）
* 支持并发对话

---

## 11.2 成本控制

* 优先规则判断（减少LLM调用）
* LLM仅在必要时调用

---

## 11.3 稳定性

* LLM失败 → fallback固定话术
* ASR失败 → 提示重试
